## 읽을 때 알아둘 점

- 질문 문장: casual_question(일상어형), LLM 모델: gemini-3.1-flash-lite, 평가셋 40건 중 40건을 실행했다.
- 평가셋은 Claude가 법령 조문을 읽고 쓴 초안이다. 사람이 확인한 일상어 질문은 0건이다(사용자가 검수를 생략하기로 했다).
- 정답 조문은 질문을 만들 때 쓴 조문이라, 조문 어휘와 겹치는 질문일수록 점수가 실제보다 높게 나올 수 있다.
- 결론 문장이 없는 비율은 구조상 높게 나온다: 서비스는 검증기가 결론 문장을 찾은 답변을 내보내지 않고 다시 쓰거나 거절한다. 검증기가 실제로 걸러낸 정도는 '답변을 다시 쓴 질문의 비율'이 보여 준다.
- 지연 시간은 Cohere 분당 한도 때문에 평가가 일부러 쉰 시간을 뺀 값이다.
